# Proposal: Actors and isolated computation

Author(s): Mike S.

Last updated: 2026-11-17

Status: Draft

Discussion at https://github.com/temperlang/temper/issues/665

## Abstract

Actors are critical for good support for BEAM runtime languages.

And JS, Dart, and other targets have mechanisms for workers that are similar in some ways.

This document will gather requirements around actors and actor isolation so we can identify a semantics that works well with languages with native support for isolated computation, and is translatable to most that don't.
