Author(s): Mike S.

Last updated: 2026-11-17

Status: Draft

Discussion at https://github.com/temperlang/temper/issues/663

## Abstract

Lets collect discussions related to binary content generation and how those connect in languages that might not have `u8[]` types.

It'd be good to move that forward especially as it's useful for the SDK use case: binary interchange formats.
It's also a prerequisite for predictable layout struct types and typed-IPC between Temper code in different language runtimes on the same machine.
